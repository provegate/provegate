  const code = { fontFamily: "var(--pg-font-mono)", fontSize: "0.85em", background: "var(--pg-bg-subtle)", border: "1px solid var(--pg-border)", borderRadius: 4, padding: "1px 5px", color: "var(--pg-accent-text)" };
  return (
    <main style={{ flex: 1, minWidth: 0, padding: "32px 44px", maxWidth: 820 }}>
      <div style={{ fontFamily: "var(--pg-font-mono)", fontSize: "0.78rem", color: "var(--pg-text-subtle)", marginBottom: 14 }}>Getting started <span style={{ opacity: 0.5 }}>/</span> Introduction</div>
      <h1 style={{ fontSize: "2.4rem", fontWeight: 700, letterSpacing: "-0.03em", margin: "0 0 14px", color: "var(--pg-text)" }}>Introduction</h1>
      <p style={{ ...p, fontSize: "1.12rem", color: "var(--pg-text)" }}>ProveGate gates autonomous coding agents on evidence a machine can check. An agent's <span style={code}>done</span> is not evidence. Work passes only when a command exits <span style={code}>0</span> — or an independent reviewer's structured verdict says <VerdictBadge verdict="pass" size="sm" />.</p>

      <h2 style={h2}>What ProveGate checks</h2>
      <p style={p}>Every gate is a command with an expected exit code. If the command isn't run, the gate isn't passed — <em>listed but not run is never passed</em>.</p>
      <Admonition type="warning" title="Listed ≠ run">A test that appears in your config but never executed does not count as evidence. ProveGate records what actually ran.</Admonition>

      <h2 style={h2}>Install</h2>
      <p style={p}>Install the CLI globally, then initialize a gate config in your repo.</p>
      <CodeBlock lang="bash" prompt>{"npm i -g provegate\ngate init"}</CodeBlock>

      <h2 style={h2}>Your first gate</h2>
      <p style={p}>Declare a check in <span style={code}>gate.toml</span>. Each gate names a command and the exit code that counts as pass.</p>
      <CodeBlock filename="gate.toml">{"[gate.test]\ncmd = \"pnpm test\"\nrequire = \"exit0\"\n\n[gate.types]\ncmd = \"tsc --noEmit\"\nrequire = \"exit0\""}</CodeBlock>
      <p style={{ ...p, marginTop: 16 }}>Run the gate. Each check prints its verdict and exit code:</p>
      <div style={{ margin: "0 0 16px" }}>
        <GateLine status="pass" name="test: unit" command="pnpm test" code={0} />
      </div>

      <h2 style={h2}>The handoff card</h2>
      <p style={p}>When a phase completes, the gate prints a handoff card — and, at the push boundary, it refuses to push for you.</p>
      <Admonition type="human" title="Push is always yours">Phases 1–3 are human, 4–7 are autonomous. The gate never pushes on your behalf: <span style={{ fontFamily: "var(--pg-font-mono)" }}>No. Push is yours.</span></Admonition>

      <h2 style={h2}>The 7-phase model</h2>
      <div style={{ margin: "8px 0 20px" }}><PhasePipeline active={4} /></div>

      <h2 style={h2}>The evidence ledger</h2>
      <p style={p}>Every run appends to an append-only ledger: the check, the command, the verdict, the exit code, and a pointer to the evidence.</p>
      <EvidenceTable caption="run a1b9f3c" rows={[
        { check: "unit tests", command: "pnpm test", verdict: "pass", code: 0, evidence: "312 passed · 4.1s" },

        { check: "e2e", command: "playwright test", verdict: "fail", code: 1, evidence: "1 failed · logs/e2e.txt" },

    </main>
  );
}
