The CLI is the primary brand surface.

Most people meet ProveGate as lines of terminal output. So output is designed, not incidental: a fixed grammar of glyphs, colour-as-signal, and box-drawing for the moments that matter — the handoff, and the refusal to push. The glyph carries status, so nothing is lost under NO_COLOR.

Status line grammar

gate run — status lines
✓ phase 4 · implementation · tsc + lint + build · exit 0 · passed
✗ phase 5 · testing · pytest · exit 1 · failed
⚠ phase 5 · contract · 1 of 3 · partial
→ phase 6 · staging smoke · operator
! phase 5 · perf budget · blocked · dependency broken
= phase 4 · lint · listed but not run is never passed
✓ passed / exit 0✗ failed / exit ≠ 0⚠ partial= skipped→ operator · handoff! blocked · overlap
