Inline geometric icon for ProveGate UI; use whenever you need a glyph — brand gate, verdicts, gate authorities, terminal chrome.

```jsx
<Icon name="gate" size={20} />
<Icon name="human" title="Human gate" />
<Icon name="check" style={{ color: "var(--pg-pass)" }} />
```

Names: `gate check cross pending human machine lock exit0 merge terminal copy arrowRight chevronRight github`. Inherits `currentColor`; set color on the element or a parent. `human` (person) and `machine` (chip) are the two distinct gate authorities — keep them visually separate in diagrams.
