ProveGate · the CLI surface

The CLI is the primary brand surface.

Most people meet ProveGate as lines of terminal output, so the output is designed: a fixed grammar of glyphs, colour-as-signal, and box-drawing for the moments that matter. Every block below is a copy-exact string the CLI prints — no animation, no fabricated output. The glyph carries status, so nothing is lost under NO_COLOR.

zero runtime deps · hand-rolled ANSI · respects NO_COLOR + non-TTY · --json for machines

Install
$ npm i -g provegate
$ gate init # scaffold the workflow tree
$ gate new my-feature # then: gate open / gate run
Command surface
gate init scaffold the workflow tree + starter configs --dry-run
gate new create the next PRD from the template <slug> [--class=X]
gate open claim a PRD: lease its surface or refuse [--steal] [--worktree]
gate status rebuild workflow state from artifacts
gate queue show the PRD queue --json
gate check lint a PRD for readiness PRD-XXX | --wiring
gate run run gated phases 4-7 + local merge --from-phase=N
gate land merge step only (alias for run --from-phase=merge)
gate push refuses — push is always yours
