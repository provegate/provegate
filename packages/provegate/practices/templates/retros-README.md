# retros/

Periodic retrospective notes — the retro → learning ritual. One dated file per
retro: `retro-YYYY-MM-DD.md`. Capture **cross-PRD themes** no single work item owns
(recurring friction, process drift, tooling gaps).

This is the lightweight half of the ritual. The enforced half is per-PRD: Phase 7 runs
the `_brain` capture protocol (`_brain/PROTOCOL.md` §7), and every PRD's declared
Durable Artifacts must land in its closing merge (rule in `AGENT_BOOTSTRAP.md`).

A retro theme that generalizes becomes a `_brain/learnings/` record — the retro note
links to it rather than duplicating it.
