> **Stub.** This reference will be auto-generated from the CLI once commands are implemented
> (roadmap Phases B–C). Today every command below exits 1 with its roadmap phase — except
> `push`, which is fully implemented.

The package installs two equivalent binaries: `provegate` and `gate`.

| Command  | Will do                                              | Status  |
| -------- | ---------------------------------------------------- | ------- |
| `init`   | scaffold workflow config + artifact tree             | Phase B |
| `new`    | create a PRD and register it in workflow state       | Phase B |
| `check`  | run the readiness gate against a PRD                 | Phase C |
| `open`   | claim a PRD: acquire locks, declare conflict surface | Phase B |
| `run`    | run gated phases 4–7 for the active PRD              | Phase C |
| `land`   | no-ff local merge with post-merge verification       | Phase C |
| `queue`  | show the PRD queue                                   | Phase B |
| `status` | show workflow state (active / next / blocked)        | Phase B |
| `push`   | refuse — push is always yours                        | done    |
